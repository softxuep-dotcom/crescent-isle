# 月湾岛 · Crescent Isle

第一期目标是可行走、可观察海浪与天空的独立海岛场景。保留 Tidewater 的原生 WebGPU 渲染、FFT 海洋、岸浪、天空、地形与角色碰撞系统；不实例化钓鱼、交易、升级及存档玩法。

## 场景方向

- 不对称月牙海湾：收短西侧岬角，保留较长的东侧海岸，中央沙滩保持适合步行的缓坡。
- 西侧木码头：入口在 `(-55, -70)`，末端在 `(-55, 22)`；船泊在外侧，珊瑚礁移到海湾东侧。
- 三间小屋：沿坡地错落分布，分别在 `(-85, -110)`、`(-24, -126)`、`(18, -145)`，用分叉木步道相连。
- 植被分区：西侧疏林、海岸棕榈簇、小屋周围的局部棕榈与林间步道。出生点及通路保持净空。
- 晴日下午与较平缓海况：保持岸浪、湿沙、折射、焦散与水下漫游，不更换原海洋算法。

坐标以米为单位，Y 向上，海平面 Y=0；海在 +Z，内陆在 -Z。地形高度数据域是 2048×2048 米，这不等于可步行陆地面积。

## 操作

点击开始，WASD 行走，鼠标环顾，Shift 快走，Space 跳跃/向上游，C 下潜。Esc 释放鼠标。Home 或“回到入口”返回出生点。F 自由相机，H 环境与画质设置，F1 操作说明。保留上游的游泳与登船能力作为探索方式。

## 三次迭代

1. 地形：修改统一海岸距离函数，使可视地形、浅海与海岸查询采用一致岸线。
2. 建筑与植被：更换村落布局、码头与码头道具坐标、步道、植被分布；移除游戏商店实例。
3. 海水与光照：设置月湾岛海况、云量、光照与后期默认值；加入独立入口、操作说明和来源页。

每阶段使用相同四组相机、1280×720、渲染比例 1、确定随机种子记录 PNG 与性能数据。结果和局限见 [REVIEW.md](REVIEW.md)，素材来源见 [ASSET_SOURCES.md](ASSET_SOURCES.md)。各阶段保留 Git 提交及标签，可回退复查。

## 范围与限制

这是桌面键鼠探索原型，需要支持 WebGPU 的浏览器。小屋为场景建筑，不包含室内交互。原始游戏代码和未启用素材作为来源保留，不代表已启用这些玩法。环境调节面板沿用上游英文标签；入口与漫游说明为中文。
